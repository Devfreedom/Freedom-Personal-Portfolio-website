## About the Project

This portfolio presents my selected projects, technical skills, development approach, and contact information in a responsive, dark-themed interface.

### Features

- **Selected projects:** Explore my delivery, healthcare, and banking applications.
- **Technical skills:** See the frontend, backend, database, and development tools I work with.
- **About section:** Learn about my approach to learning through hands-on development.
- **Contact links:** Connect with me through email and my social profiles.
- **Responsive design:** Layouts adapted for mobile, tablet, and desktop screens.
- **Accessible navigation:** Semantic page sections, keyboard-focus styles, and reduced-motion support.
- **Reusable components:** UI sections organised into maintainable React components.

## Getting Started

To run the portfolio locally, you need Node.js and npm installed.

### 1. Clone the repository

```bash
git clone https://github.com/Devfreedom/Freedom-Personal-Portfolio-website.git
cd Freedom-Personal-Portfolio-website
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The development server automatically refreshes the page as you make changes.

## Available Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Start the development server |
| `npm run lint` | Run ESLint |
| `npm run build` | Create a production build |
| `npm run start` | Start the production server after building |

## Deployment

The portfolio can be deployed using [Vercel](https://vercel.com/), which supports Next.js applications.

To deploy, import the repository into Vercel, confirm the project settings, and deploy the application. Run the production build locally before deploying changes.

For more information, see the [Next.js deployment documentation](https://nextjs.org/docs/app/building-your-application/deploying).
